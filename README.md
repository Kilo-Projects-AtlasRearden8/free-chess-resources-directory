# Free Chess Resources Directory

A beginner-friendly directory of free chess resources: Lichess, Chess.com free tiers, puzzles, tactics trainers, opening databases, and endgame studies.

This is for anyone who wants to play and learn chess without spending money. Every listing is free (or has a genuine free tier) and includes cost, platform, simple steps to get started, and an official link. No affiliate links. No paid resources.

## What's inside

| File | What it is |
|------|------------|
| `resources.md` | Human-readable Markdown directory of all 9 listings |
| `resources.json` | Structured data (same 9 listings) that powers the site |
| `index.html` | Static website you can open in any browser |

## How to run it

There is nothing to install and no build step.

1. Open this folder on your computer.
2. Double-click `index.html` to open it in your web browser.
3. Use the search box to find resources by name, category, platform, or cost.
4. Click a category button (Play, Puzzles, Tactics trainer, etc.) to filter.
5. Click "Official link" on any card to visit that resource's site.

The site works entirely in your browser. You do not need a web server, an internet connection beyond visiting the official links, or an account to start using most of these resources.

## The 9 free resources

- **Lichess** — play, puzzles, tactics, studies, opening explorer (100% free)
- **Chess.com (free tier)** — play and puzzles within free daily limits
- **Lichess Puzzles** — tactics puzzles with adjustable difficulty
- **Chess.com Puzzles** — daily puzzles on the free tier
- **Lichess Tactics Trainer** — tactics adapted to your rating
- **Lichess Opening Explorer** — opening statistics from millions of games
- **365Chess.com Opening Database** — openings by name or ECO code
- **Lichess Studies (endgame studies)** — community endgame studies
- **Lichess Endgame Training** — practice endgames against the computer

See `resources.md` for full details on each listing.
