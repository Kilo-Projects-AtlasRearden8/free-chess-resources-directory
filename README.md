# Free Chess Resources Directory

A beginner-friendly directory of free chess resources: Lichess, Chess.com free tiers, puzzles, tactics trainers, opening databases, and endgame studies.

Every listing includes cost, platform, steps to get started, and an official link. All resources are free (or have a genuine free tier). No affiliate links. No paid resources included.

## What's inside

- `resources.md` &mdash; human-readable Markdown directory of all listings
- `resources.json` &mdash; structured data powering the static site
- `index.html`, `style.css`, `app.js` &mdash; static HTML site with client-side search (no build step, no server required)
- `LICENSE` &mdash; MIT License
- `STATUS.md` &mdash; build notes, how to run, verification results, known gaps

## How to run

Open `index.html` in any modern web browser. That's it &mdash; no install, no build step, no server required. The site loads `resources.json` and filters results entirely in the browser.

If you serve the folder over HTTP (for example `python3 -m http.server 8000`), the fetch of `resources.json` works the same way; opening the file directly also works in most browsers.
